#### A simple bash script to run on your Linux device.
* Always make sure you NEVER run any scripts from untrusted sources!

Usage:

Run `wget -O - https://raw.githubusercontent.com/GoGit-IT/bash/Home/setup.sh | bash` or
* `wget -O - https://raw.githubusercontent.com/GoGit-IT/bash/Home/setup.sh | sudo bash` or
* `bash -c "$(curl -sSL https://raw.githubusercontent.com/GoGit-IT/bash/Home/setup.sh)"` to see if you can run scripts from GitHub.
